# Vision-Based Hand Gesture Screenshot System

The **Vision-Based Hand Gesture Screenshot System** is a computer vision application that allows users to capture screenshots using **hand gestures detected through a webcam**.

The system uses **MediaPipe and OpenCV** to detect finger positions in real time. When **five fingers are shown**, the program automatically captures a screenshot and saves it to a designated folder.

This project demonstrates the use of **AI-based gesture recognition for touchless computer interaction**.

---

## Features

* Real-time **hand gesture detection**
* **Automatic screenshot capture**
* Gesture-based control system
* **5 fingers ✋ trigger screenshot**
* Web interface with **Start and Stop camera buttons**
* Screenshots automatically stored in a folder
* Animated **bubble background UI**

---


## How the System Works

1. Open the web interface.
2. Click **Start Camera**.
3. The webcam activates and begins detecting hand gestures.
4. When **five fingers are detected**, the system captures a screenshot.
5. The screenshot is saved automatically inside the **shot_saver** folder.
6. Click **Stop Camera** to stop the camera and the program.
